# Дорожная карта редактора статей

Актуально: 21 сентября 2026. Порядок этапов можно менять после реальной работы со статьями.

| Этап | Результат | Критерий готовности |
| --- | --- | --- |
| **0 · OUTMAX MVP — готово** | Локальный редактор, импорт HTML/ZIP и статьи OUTMAX по ссылке, товары, содержание, таблицы, выбор фото, превью, HTML и ZIP. На GitHub Pages работает браузерная версия. | Статью можно создать, сохранить, снова открыть и передать редактору в ZIP. |
| **1 · Надёжная работа** | Проверка длинных статей, исправление ошибок редактирования, автосохранение, отмена действий и понятное восстановление черновика. | После случайного закрытия вкладки работа восстанавливается; перестановка и удаление блоков отменяются. |
| **2 · Полный онлайн-режим** | Отдельный серверный API для загрузки товаров и статей OUTMAX; согласованный способ хранения и доступа к черновикам. | По артикулу и ссылке онлайн выполняются те же действия, что локально. Черновик доступен с другого устройства после входа. |
| **3 · ХАСЛ** | Отдельные шаблон, стили, редакционные правила и источники товаров для второго сайта; переключатель проекта. | Статья ХАСЛ оформляется и экспортируется без стилей или ссылок OUTMAX. |
| **4 · Публикация** | Предпубликационная проверка ссылок, якорей и медиа; удобная передача на сайт. | Редактор показывает найденные проблемы и выдаёт чистый HTML и ресурсы для загрузки. |

## Важные границы текущей версии

- GitHub Pages размещает интерфейс, но не запускает Python. Поэтому автоматический импорт по URL и поиск товаров по артикулам работают в локальной версии; онлайн товары добавляются вручную.
- Локальные черновики находятся в `articles/`, а онлайн-черновики — в хранилище конкретного браузера. Они не синхронизируются. ZIP — способ переноса и резервного копирования до этапа 2.
- Фото товаров и медиа импортированных статей остаются по прямым ссылкам на источник; собственные загруженные изображения входят в ZIP.

## Решения перед этапами 2 и 3

1. Выбрать место для серверного API и хранения черновиков, определить доступ редакторов. Публикация исходников на GitHub Pages сама по себе этого не решает.
2. Получить образец статьи ХАСЛ, логотип, стили, промпт и правила ссылок на товары. До этого сохраняем фокус на OUTMAX.
