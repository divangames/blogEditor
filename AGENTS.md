# Работа с редакторами OUTMAX / ХАСЛ

Следуйте существующей архитектуре Python + обычный JavaScript и сохраняйте стиль действующего приложения.

## Инструкции и история изменений

- При каждом изменении поведения или добавлении функции обновляйте `CHANGELOG.md` и соответствующую инструкцию в `instructions/articles.json` в том же изменении.
- Для новой пользовательской функции добавьте пошаговое руководство: где найти действие, что заполнить, ожидаемый результат, ограничения и решение типовых ошибок. Помещайте его в подходящую группу и добавляйте связанные инструкции.
- Меняя интерфейс, переснимите относящиеся к нему скриншоты в `instructions/screens/` на изолированном тестовом сервере, без личных данных и секретов. Обновите дату актуализации материалов.
- Ченжлог на странице `/instructions/` собирается из корневого `CHANGELOG.md` автоматически через `build_instructions.py`. Не ведите отдельную копию истории вручную.
- Проверьте поиск, прямую ссылку на изменённое руководство, навигацию редакторов и отображение на телефоне. Перед публикацией выполните `node tests/instructions-check.cjs` с локальным стендом `python tests/instructions-server.py`. Для скриншотов используйте `node tests/instructions-capture.cjs`; стенд использует только демонстрационный аккаунт.
- Сборка `prepare_full_deploy.py` встраивает страницу и скриншоты в WSGI для совместимости с VPS, который может не копировать новые файлы.
