Собирайте разделы и содержание, добавляйте товары, сравнивайте их свойства и передавайте готовую статью редактору в ZIP.

Открыть редактор онлайнСкачать редакторОткрыть исходный код

Онлайн-редактор работает прямо в браузере: создавайте статью, загружайте свои изображения, сохраняйте черновики и скачивайте ZIP. Черновики хранятся только в этом браузере. Для автоматической загрузки товаров по артикулам и импорта статьи по ссылке запустите скачанную версию: эти операции требуют Python-сервера.

Редактор в работе

Скриншоты показывают возможности редактора. Нажмите на изображение, чтобы рассмотреть его в полном размере.

01 · Товары

В онлайн-версии добавляйте карточки товара вручную. Локальная версия загружает несколько артикулов или ссылок автоматически.

02 · Структура

Редактируйте разделы, содержание и якоря. Таблица сравнения использует подтверждённые свойства товаров.

03 · Передача

Сохраните HTML и ZIP с черновиком и загруженными изображениями. Фото товаров остаются прямыми ссылками на OUTMAX.

Запуск на Windows

  1. Установите Python 3, если он ещё не установлен.
  2. Скачайте ZIP проекта и распакуйте папку.
  3. Откройте «Редактор OUTMAX.bat» и выберите пункт 1.
  4. Редактор откроется по адресу http://127.0.0.1:8765/.
