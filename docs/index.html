Статьи OUTMAX от черновика до HTML

Собирайте разделы и содержание, подтягивайте товары по артикулам, сравнивайте их свойства и передавайте готовую статью редактору в ZIP.

Скачать редакторОткрыть исходный код

Как работает редактор. Скачайте проект и запустите «Редактор OUTMAX.bat» на Windows. Редактор использует локальный Python-сервер для загрузки карточек OUTMAX и сохранения статей; эта страница GitHub Pages служит для загрузки проекта.

01 · Товары

Вставьте несколько артикулов или ссылок. Карточки с фото появятся в панели «Товары» и перетаскиваются в статью.

02 · Структура

Редактируйте разделы, содержание и якоря. Таблица сравнения использует подтверждённые свойства товаров.

03 · Передача

Сохраните HTML и ZIP с черновиком и загруженными изображениями. Фото товаров остаются прямыми ссылками на OUTMAX.

Запуск на Windows

  1. Установите Python 3, если он ещё не установлен.
  2. Скачайте ZIP проекта и распакуйте папку.
  3. Откройте «Редактор OUTMAX.bat» и выберите пункт 1.
  4. Редактор откроется по адресу http://127.0.0.1:8765/.
