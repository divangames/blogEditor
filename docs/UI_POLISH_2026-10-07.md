# Исправление панели типографики

Применён emil-design-eng: согласованные размеры контролов, единый шрифт интерфейса, явный focus-visible, hover только на подходящих устройствах, мгновенное форматирование без декоративной анимации. Авторизация на исправление дана прямым запросом пользователя.

| Before | After | Why |
| --- | --- | --- |
| Поле семейства без заданных border/padding/radius выглядело как системный input | Единый нейтральный border 1 px, radius 6 px, внутренние отступы | Поле выглядит частью панели |
| Название шрифта меняло шрифт самого контрола, а поля были 16 px на desktop | UI использует Open Sans 12 px на desktop; реальный шрифт меняется только у текста статьи | Форматирование документа не меняет визуальную систему интерфейса |
| Семейство и размер находились внутри одного label | Два отдельных label в общей группе; desktop 32 px, mobile 44 px/16 px | Предсказуемый фокус, выравнивание, отсутствие zoom на телефоне |
| Новый инструмент назывался «Таблица сравнения» | «Таблица сравнения товаров», отдельная строка инструментов | Уточнено назначение и сохранено отличие от обычной таблицы |

Визуальная регрессия: tests/toolbar-polish-check.cjs проверяет размеры, border/radius/padding, шрифт UI, длинное семейство Times New Roman, дробный размер 57.5 и мобильный экран во всех редакторах. Снимки: release/ui-check/screens/toolbar-*-desktop.png и toolbar-*-mobile.png.
## Создание статьи

| Before | After | Why |
| --- | --- | --- |
| В верхней панели не было создания отдельной статьи | Нейтральная кнопка с плюсом рядом с сохранением | Действие доступно из рабочего редактора |
| Из личного архива нельзя начать новый материал | Та же кнопка в пользовательских архивах | Единый вход для всех аккаунтов |
| На узкой панели мало места для трёх действий | Новая кнопка занимает отдельную строку, остальные две остаются рядом | Подписи читаются без переполнения |
