# Интерфейс Tiptap по emil-design-eng

Использован установленный skill [emil-design-eng](https://github.com/emilkowalski/skills). Проверка — Playwright в Edge.

| Before | After | Why |
| --- | --- | --- |
| Все действия выглядели одинаковыми | Основное сохранение выделено; открытие, экспорт и примеры отделены от форматирования | Понятна последовательность работы |
| Несогласованные размеры и шрифты контролов | Общие токены, 38 px desktop / 44 px mobile, 13/16 px для полей | Интерфейс читается и удобен для касания |
| Техническая информация занимала рабочую область | Компактный статус, счётчик символов и раскрываемая информация | Больше места статье |
| Панель могла оказаться под sticky-toolbar | Отступ прокрутки учитывает реальную высоту инструментов | Выбранные настройки остаются видимыми |
| Не было ясного состояния просмотра оригинала | aria-pressed и активный стиль | Кнопка показывает текущий режим |

Клавиатурные действия и редактирование не анимируются. Hover применяется для мыши; focus-visible явный. Типографика статьи не заменяется интерфейсной. Проверены ширины 1440, 1280, 768, 375 px и работа панелей/undo/JSON. Снимки: release/tiptap-prototype/ui-polish/.
