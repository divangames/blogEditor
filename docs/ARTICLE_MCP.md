# MCP редактора статей

Мост использует отдельную локальную сессию браузера и реальные команды основного редактора OUTMAX/ХАСЛ. Поддерживается MCP stdio 2025-11-25; протокол проверен по [официальной спецификации](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports). Протокол 2026-07-28 этим мостом не заявлен.

## Запуск

Команда MCP-клиента — `node`, единственный аргумент — абсолютный путь к `tools/article-mcp.cjs` в вашей копии проекта. Используйте окружение клиента для `EDITOR_MCP_URL`, `EDITOR_MCP_USER`, `EDITOR_MCP_PASSWORD`. По умолчанию URL — `https://news.outmax-office.ru`. Пароли не передавайте в командной строке и не сохраняйте в отслеживаемых Git-файлах.

Node.js и Playwright должны быть установлены локально. По умолчанию модуль берётся из `release/ui-check/node_modules/playwright`. Для другой установки задайте абсолютный путь модуля через `EDITOR_PLAYWRIGHT_MODULE`. На Windows запускается установленный Edge; на других ОС нужен установленный Chromium Playwright. Сам скрипт не устанавливает браузер и не меняет настройки Codex.

## Работа

Начинайте с `list_commands` и `inspect_document`. `open_document` открывает запись текущего аккаунта; `new_document` создаёт новый несохранённый текст. `select_text` выбирает точное вхождение, `type_text` вставляет обычный текст. `execute` ограничен форматированием, стилями, отменой, повтором, режимом фокуса, поиском/заменой и вставкой ссылки с явным адресом. `edit.find` принимает query, caseSensitive и wholeWord; `edit.replaceFound` — text и логический all. `batch` выполняет до 40 повторяемых команд одним шагом истории.

Автосохранение отключено только в агентской сессии. `save_document` использует действующий механизм версий и конфликтов; для нового документа нужен понятный заголовок. Несохранённые изменения блокируют переход в другую запись, пока клиент явно не сохранит их или не передаст `discard_changes: true`. Перед завершением процесса сохраните результат: контекст браузера временный.

`export_document` создаёт DOCX, Markdown или PDF внутри `output/mcp-export` и возвращает путь. Изменения проверяются через `inspect_document` и полученный файл. Мост не предоставляет shell/eval, настройку API-ключей, вызов ИИ, отправку писем и доступ к открытой вкладке пользователя.

## Проверки

Запустите `python tests/instructions-server.py`, затем `node tests/article-mcp-check.cjs`. Сценарий использует только демонстрационный аккаунт, сохраняет контрольную запись и проверяет JSON-RPC, команды, выделение, вставку, пакетную отмену, защиту переходов, явное сохранение, повторное открытие и DOCX. Производственная проверка не создаёт тестовые статьи.

## Ссылки

После `select_text` вызовите `execute` с `command: "link.insert"` и `params: {"url": "https://example.com"}` либо #якорем. Действие использует прежний createLink и отменяется командой `edit.undo`. `link.open` недоступна агенту, поскольку открывает интерактивное поле адреса; ссылки не входят в макросы/пакеты форматирования. Для записи результата на сервер по-прежнему нужен явный `save_document`.
