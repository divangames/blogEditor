# Проверка совместимости Tiptap — 7 октября 2026

**Решение: миграцию рабочего редактора пока не выполнять.** Стандартные расширения не сохраняют оформление и якоря реальных материалов обоих брендов. Это результат базового эксперимента, не вывод о невозможности собственной реализации на Tiptap.

## Исходники и метод

- OUTMAX: `OUTMAX/OUTMAX_TOP10_ZIMA_2027_PUBLICATION_PACK_V2_1/article-body.html`.
- ХАСЛ: `ХАСЛ/HASL_TOP10_OSEN_2026_PUBLICATION_PACK_V4_4/article-body.html`.
- @tiptap/core, starter-kit, extension-image, extension-table: 3.31.4; jsdom: 30.1.2. Версии зафиксированы отдельным lockfile в tests/tiptap-spike.
- Создание Tiptap Editor в jsdom, исходный HTML → JSON → HTML, восстановление JSON, добавление тестового абзаца и undo.
- В headless Microsoft Edge сняты исходный и экспортированный HTML при ширине 1280 и 375 px.
- Доступные локальные картинки встроены только для снимков (5 OUTMAX, 6 ХАСЛ); внешние HTTP-запросы заблокированы. Оригиналы материалов и рабочие черновики не изменялись.

## Результаты

OUTMAX:

- Нормализованный текст, последовательность заголовков и пары src/alt всех 49 изображений сохранены.
- Восстановление JSON и отмена тестового абзаца прошли.
- Элементы ссылок: 133 → 89. Проверка точной последовательности href не прошла; нельзя считать ссылочную структуру сохранённой.
- Идентификаторы: 20 → 0. Оглавление с якорными ссылками теряет цели перехода.
- Элементы с inline-стилями: 733 → 185; обёртки article/section/header/nav/figure/figcaption: 26 → 0.

ХАСЛ:

- Нормализованный текст, заголовки и пары src/alt всех 46 изображений сохранены.
- Восстановление JSON и undo прошли.
- Элементы ссылок: 125 → 85; точная последовательность href не сохранена.
- Идентификаторы: 16 → 0; элементы со стилями: 753 → 190; смысловые обёртки: 23 → 0.

Число таблиц и ячеек совпало у обоих материалов. Это не доказывает сохранность их размеров, содержимого каждой ячейки и оформления. Часть оставшихся стилей генерирует сам TableKit; совпадение количества атрибутов не заменяет сравнение их значений.

На снимках OUTMAX после экспорта видно исчезновение карточного оформления и ограничения ширины изображений. Потеря исходных style/id/обёрток подтверждена DOM-проверкой для обоих брендов. Снимки не являются полным доказательством сохранности медиа: большинство фотографий — внешние, сетевые загрузки отключены.

## Артефакты и повторение

Скрипт: `tests/tiptap-compatibility-check.cjs`. Зависимости и результаты находятся отдельно от рабочего приложения в игнорируемой папке `release/tiptap-check`.

PowerShell из корня проекта:

```powershell
New-Item -ItemType Directory -Path release/tiptap-check -Force | Out-Null
Copy-Item tests/tiptap-spike/package.json release/tiptap-check/package.json
Copy-Item tests/tiptap-spike/package-lock.json release/tiptap-check/package-lock.json
npm ci --prefix release/tiptap-check --no-audit --no-fund
# Если существующие browser-зависимости отсутствуют:
npm install --prefix release/ui-check playwright
node tests/tiptap-compatibility-check.cjs
```

Требуется Node.js, Microsoft Edge и оба исходных публикационных пакета. OUTMAX/ и release/ не переносятся через Git. В ограниченной Windows-песочнице Edge завершился до открытия страницы; повторный разрешённый запуск вне песочницы завершился успешно.

Результаты: `release/tiptap-check/results/report.json`, `*-document.json`, `*-source.html`, `*-export.html`, снимки `*-source-1280.png`, `*-source-375.png`, `*-export-1280.png`, `*-export-375.png`.

Код завершения 0 означает успешное проведение эксперимента. Готовность миграции определяется полем migrationAllowed; сейчас оно false у обоих брендов.

## Что ещё необходимо доказать до миграции

1. Собственные узлы товара, сравнения, галереи, рейтинга, CTA, оглавления и секций с нужными атрибутами и стабильными идентификаторами.
2. HTML → JSON → правка → повторное открытие → текущий экспорт HTML/ZIP → повторный импорт без потери текста, блоков, ссылок, якорей и медиа.
3. Экспорт для обоих доменов каждого бренда, копирование локальных ресурсов, сохранность стилей и отображение desktop/mobile.
4. Перенос привязок обсуждений, таблицы/списки, ввод/выделение, Word/Google Docs paste, IME и реальная работа на телефоне.
5. Длинные документы, сохранение курсора и прокрутки, лицензии расширений, миграция старых черновиков и откат.

В этом эксперименте не проверялись production-импортёры, текущие Python/браузерные экспортёры, ZIP-упаковка ресурсов, CMS и совместное редактирование. Их проверки остаются обязательным условием, а не считаются пройденными по результатам JSON/HTML roundtrip.

Документация: [строгая схема Tiptap](https://tiptap.dev/docs/editor/core-concepts/schema), [Vanilla JavaScript](https://tiptap.dev/docs/editor/getting-started/install/vanilla-javascript).
