# Редактор статей OUTMAX

Запуск в Windows: откройте `Редактор OUTMAX.bat` (или `editor.bat`) и выберите **1** для запуска, **2** для отправки кода в [GitHub](https://github.com/divangames/blogEditor). Батник использует английские надписи для совместимости с `cmd.exe`. Если редактор уже работает, откроется его вкладка. Папка `articles/` с черновиками не публикуется. Репозиторий хранит исходный код, а для работы самого Python-сервера нужен отдельный хостинг. Или в PowerShell выполните `python -m pip install -r requirements.txt`, затем `python app.py`. После запуска откройте `http://127.0.0.1:8765`.

Редактор принимает точную ссылку на карточку OUTMAX или артикул. Свои изображения можно загрузить кнопкой. Кнопка «Сохранить» создаёт `articles/<название>.html`, `articles/<название>.json` и папку `articles/<название>_files` для загруженных изображений; ZIP собирает их для передачи редактору.

Фото товаров используются по прямым URL OUTMAX и не копируются в папку статьи. В папку ресурсов сохраняются только изображения, загруженные вручную. Щелчок по элементу статьи открывает панель удаления; у заголовка раздела можно скрыть или вернуть линию. Двойной щелчок по изображению открывает настройки кадрирования, размера, выравнивания, alt и замены файла.

«Открыть статью (HTML/ZIP)» загружает локальный `.html`, `.htm`, JSON черновика или ZIP с HTML и папкой изображений. «Адаптировать статью» перестраивает заголовок, разделы, содержание и таблицы под дизайн OUTMAX. Для статьи с локальными относительными изображениями удобнее открыть ZIP: при открытии одиночного HTML браузер не получает доступ к соседним файлам автоматически.

Адаптация меняет структуру и оформление, сохраняя исходный текст и ссылки. Редактору всё равно нужно проверить факты, цены, акции и alt изображений перед публикацией.

Текст редактируется прямо на холсте. Ссылка «HTML» открывает исходный код статьи для точной правки. Превью обновляется после каждого изменения. Для публикации можно передать HTML и соседнюю папку ресурсов; пути к картинкам в HTML относительные. Данные карточки товара и тексты статьи нужно проверить перед размещением.
