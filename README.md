# Редактор статей OUTMAX

Запуск в Windows: откройте `Редактор OUTMAX.bat` (или `editor.bat`). Пункты меню: **1** — запустить редактор, **2** — сделать коммит и пуш в [GitHub](https://github.com/divangames/blogEditor), **3** — обновить [GitHub Pages](https://divangames.github.io/blogEditor/) из уже отправленного кода, **4** — выполнить пункты 2 и 3 подряд. Батник использует английские надписи для совместимости с `cmd.exe`. Если редактор уже работает, пункт 1 откроет его вкладку. Папка `articles/` с черновиками не публикуется. Страница GitHub Pages размещена в `docs/` и открывает браузерную версию редактора; Python-сервер на GitHub Pages не запускается. Или в PowerShell выполните `python -m pip install -r requirements.txt`, затем `python app.py`. После запуска откройте `http://127.0.0.1:8765`.

На GitHub Pages есть кнопка «Открыть редактор онлайн». Браузерная версия позволяет редактировать и адаптировать загруженный HTML/ZIP, добавлять товары вручную, загружать изображения, хранить черновики в IndexedDB этого браузера и скачивать ZIP. Черновики не синхронизируются между устройствами — регулярно скачивайте ZIP. Автоматическое получение товаров по артикулам и импорт статьи по ссылке доступны в локальной версии: браузер не может читать HTML OUTMAX напрямую из-за политики CORS, а GitHub Pages не запускает Python-сервер.

На широком экране левое меню и рабочая область имеют независимую прокрутку: наведите мышь на нужную область и прокручивайте её, не сдвигая вторую.

В поле «Товары» можно вставить несколько артикулов или ссылок через запятую или с новой строки. Карточки загружаются в боковую панель с миниатюрой и названием. Их можно перетащить на холст или вставить кнопкой. Таблица сравнения создаёт строку для каждого загруженного товара и заполняет до трёх критериев подтверждёнными свойствами карточек. «Не указано» означает отсутствие сведений, а не отсутствие свойства; критерии и значения можно править вручную. Свои изображения можно загрузить кнопкой. «Сохранить» создаёт `articles/<название>.html`, `articles/<название>.json` и папку `articles/<название>_files` для загруженных изображений; ZIP собирает их для передачи редактору. Список товаров сохраняется в JSON и восстанавливается при открытии ZIP.

Чтобы выбрать фото товара в таблице, нажмите на миниатюру или на строку модели и затем «Выбрать фото товара». Редактор показывает кадры из галереи соответствующего товара; можно также вставить прямую HTTPS-ссылку на изображение. Выбор меняет только эту строку таблицы и сохраняется в HTML без загрузки фото на компьютер.

В панели «Содержание и разделы» можно добавлять, переименовывать, переставлять и удалять разделы, задавать им якоря. Для каждого пункта содержания можно изменить текст и выбрать цель среди разделов и товаров, вставленных в статью.

Фото товаров используются по прямым URL OUTMAX и не копируются в папку статьи. В папку ресурсов сохраняются только изображения, загруженные вручную. Щелчок по элементу статьи открывает панель удаления; у заголовка раздела можно скрыть или вернуть линию. Двойной щелчок по изображению открывает настройки кадрирования, размера, выравнивания, alt и замены файла.

Чтобы продолжить писать вне изображения, товара, таблицы или другого блока, щёлкните в свободной области холста либо выберите блок и нажмите «Текст выше» или «Текст ниже». Редактор создаст отдельный абзац и поставит в него курсор.

Для вставки раздела, товара, таблицы или изображения наведите курсор на нужный промежуток в статье и нажмите «Вставить сюда» на красной линии. Затем используйте кнопку добавления слева: новый блок появится в выбранном месте. Кнопки раздела, содержания, выделенного блока и таблицы, а также товар из панели можно перетащить прямо на нужную позицию. Чтобы переставить уже вставленный блок, выберите его и перетащите за кнопку «Перетащить блок» на новое место.

«Открыть статью (HTML/ZIP)» загружает локальный `.html`, `.htm`, JSON черновика или ZIP с HTML и папкой изображений. «Адаптировать статью» перестраивает заголовок, разделы, содержание и таблицы под дизайн OUTMAX. Для статьи с локальными относительными изображениями удобнее открыть ZIP: при открытии одиночного HTML браузер не получает доступ к соседним файлам автоматически.

«Адаптировать статью по ссылке» принимает адрес `https://outmaxshop.ru/article/…`. Редактор загружает только содержимое статьи без меню сайта, переносит текст, разделы, содержание, карточки товаров, таблицы, фото и поддерживаемые видеоплееры, затем применяет оформление OUTMAX. Изображения и видео остаются по внешним URL: редактор не скачивает их в папку статьи и не включает в ZIP. Импортированная статья остаётся черновиком до нажатия «Сохранить». Ссылки и медиа могут перестать работать, если источник изменится или удалит файлы.

Адаптация меняет структуру и оформление, сохраняя исходный текст и ссылки. Редактору всё равно нужно проверить факты, цены, акции и alt изображений перед публикацией.

Текст редактируется прямо на холсте. Выпадающий список «Стиль текста H» превращает текущий блок в обычный текст или заголовок H1–H6; H7 сохраняется как оформленный абзац, потому что такого тега в HTML нет. Ссылка «HTML» открывает исходный код статьи для точной правки. Превью обновляется после каждого изменения. Для публикации можно передать HTML и соседнюю папку ресурсов; пути к картинкам в HTML относительные. Данные карточки товара и тексты статьи нужно проверить перед размещением.
