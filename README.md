# Редактор статей OUTMAX

Для работы на другом компьютере: [список задач](TODO.md) и [дорожная карта](ROADMAP.md).

Запуск в Windows: откройте `Редактор OUTMAX.bat` (или `editor.bat`). Пункты меню: **1** — запустить редактор, **2** — сделать коммит и пуш в [GitHub](https://github.com/divangames/blogEditor), **3** — обновить [GitHub Pages](https://divangames.github.io/blogEditor/) из уже отправленного кода, **4** — выполнить пункты 2 и 3 подряд, **5** — подготовить папку `server-deploy/` и архив `server-deploy.zip` для собственного сервера. Меню автоматически разрешает Git работать с текущей папкой, даже если Windows показывает другого владельца каталога. Если вход GitHub устарел, пункты 2–4 откроют браузер для повторной авторизации и продолжат работу после подтверждения. В архиве файлы сайта лежат сразу в корне: содержимое папки или архива можно загружать в корень сайта на хостинге. Батник использует английские надписи для совместимости с `cmd.exe`. Если редактор уже работает, пункт 1 откроет его вкладку. Папка `articles/` с черновиками не публикуется. Страница GitHub Pages размещена в `docs/` и открывает браузерную версию редактора; Python-сервер на GitHub Pages не запускается. Или в PowerShell выполните `python -m pip install -r requirements.txt`, затем `python app.py`. После запуска откройте `http://127.0.0.1:8765`.

Для полноценного размещения без отдельной главной страницы в BAT доступны пункты **6** — пакет VPS/Docker, **7** — пакет Python WSGI/Passenger и **8** — сразу оба пакета. Результаты создаются в `release/outmax-editor-docker(.zip)` и `release/outmax-editor-python-hosting(.zip)`. Оба варианта открывают редактор непосредственно по адресу `/`, поддерживают серверные черновики, изображения, импорт товаров и статей, а также защищены сгенерированным логином и паролем. Учётные данные выводятся после сборки и записываются в инструкции внутри пакета.

На GitHub Pages есть кнопка «Открыть редактор онлайн». Браузерная версия позволяет редактировать и адаптировать загруженный HTML/ZIP, добавлять товары вручную, загружать изображения, хранить черновики в IndexedDB этого браузера и скачивать ZIP. Черновики не синхронизируются между устройствами — регулярно скачивайте ZIP. Автоматическое получение товаров по артикулам и импорт статьи по ссылке доступны в локальной версии: браузер не может читать HTML OUTMAX напрямую из-за политики CORS, а GitHub Pages не запускает Python-сервер.

На широком экране левое меню и полотно статьи прокручиваются независимо. Заголовок редактора, вкладки и инструменты форматирования остаются видимыми. Превью и HTML-код прокручиваются внутри своих областей.

В поле «Товары» можно вставить несколько артикулов или ссылок через запятую или с новой строки. Поддерживаются карточки `outmaxshop.ru` и `outmaxshop.com`; для артикула без полной ссылки домен выбирается над полем ввода. Одинаковые товарные пути на `.ru` и `.com` распознаются как один товар. Карточки загружаются в боковую панель с миниатюрой и названием. Их можно перетащить на холст или вставить кнопкой. Таблица сравнения создаёт строку для каждого загруженного товара и заполняет до трёх критериев подтверждёнными свойствами карточек. «Не указано» означает отсутствие сведений, а не отсутствие свойства; критерии и значения можно править вручную. Свои изображения можно загрузить кнопкой. «Сохранить» создаёт `articles/<название>.html`, `articles/<название>.json` и папку `articles/<название>_files` для загруженных изображений. Список товаров сохраняется в JSON и восстанавливается при открытии ZIP.

Чтобы выбрать фото товара в таблице, нажмите на миниатюру или на строку модели и затем «Выбрать фото товара». Редактор показывает кадры из галереи соответствующего товара; можно также вставить прямую HTTPS-ссылку на изображение. Выбор меняет только эту строку таблицы и сохраняется в HTML без загрузки фото на компьютер.

В панели «Содержание и разделы» можно добавлять, переименовывать, переставлять и удалять разделы, задавать им якоря. Для каждого пункта содержания можно изменить текст и выбрать цель среди разделов и товаров, вставленных в статью.

В панели «Блоки и медиа» доступна кнопка с произвольным текстом в трёх вариантах: красная, чёрная и белая с чёрной рамкой. Кнопка может вести на внешнюю ссылку или на якорь текущей статьи. Внешняя ссылка по умолчанию открывается в новом окне; для якоря эта настройка отключается автоматически.

Фото с `outmaxshop.ru` и `outmaxshop.com` используются по прямым URL и не копируются в папку статьи. Изображения с других сайтов при сохранении автоматически скачиваются в папку ресурсов и включаются в экспортный ZIP; недоступные или неподдерживаемые файлы остаются по исходному адресу с предупреждением. Щелчок по элементу статьи открывает панель удаления; у заголовка раздела можно скрыть или вернуть линию. Двойной щелчок по изображению открывает настройки кадрирования, размера, выравнивания, alt и замены файла.

Чтобы продолжить писать вне изображения, товара, таблицы или другого блока, щёлкните в свободной области холста либо выберите блок и нажмите «Текст выше» или «Текст ниже». Редактор создаст отдельный абзац и поставит в него курсор.

Для вставки раздела, товара, таблицы или изображения наведите курсор на нужный промежуток в статье и нажмите «Вставить сюда» на красной линии. Затем используйте кнопку добавления слева: новый блок появится в выбранном месте. Кнопки раздела, содержания, выделенного блока и таблицы, а также товар из панели можно перетащить прямо на нужную позицию. Чтобы переставить уже вставленный блок, выберите его и перетащите за кнопку «Перетащить блок» на новое место.

«Открыть статью (HTML/ZIP)» загружает локальный `.html`, `.htm`, JSON черновика или ZIP с HTML и папкой изображений. Для распакованного публикационного комплекта используйте «Открыть папку статьи с фото»: редактор сам выбирает HTML, находит относительные пути вроде `assets/images/...`, загружает использованные изображения и включает их в будущий ZIP. Обычный публикационный HTML автоматически адаптируется: редактор распознаёт разделы, содержание, товарные карточки, галереи и кнопки. «Адаптировать статью» можно использовать повторно для ручной перестройки уже открытого материала.

«Адаптировать статью по ссылке» принимает адреса `outmaxshop.ru/article/…`, `outmaxshop.com/article/…` и новостные адреса вида `/17-news/…` или `/news/…`; `https://` можно не вводить. Редактор загружает только содержимое статьи без меню сайта, переносит текст, разделы, содержание, карточки товаров, таблицы, фото и поддерживаемые видеоплееры, затем применяет оформление OUTMAX. Отдельные ссылки-призывы вроде «Смотреть все кроссовки →» автоматически оформляются как кнопки. При сохранении сторонние изображения скачиваются в ресурсы статьи, а изображения OUTMAX остаются по прямым URL. Импортированная статья остаётся черновиком до нажатия «Сохранить».

Кнопка «Экспорт HTML / ZIP» предлагает подготовить ссылки для `outmaxshop.ru`, `outmaxshop.com` или сразу для обоих сайтов. В последнем случае ZIP содержит два HTML-файла с одинаковым материалом и разными доменами ссылок OUTMAX. Итоговый HTML рассчитан на ограниченный редактор админки: всё оформление записывается в атрибуты `style`, внешний CSS и классы не требуются, а неподдерживаемые `loading`, `decoding`, `role`, `aria-*`, `data-*` и `tabindex` удаляются. Изображения OUTMAX используют обычный прямой `src`. Внутренние якоря и ссылки на сторонние сайты не изменяются.

Адаптация меняет структуру и оформление, сохраняя исходный текст и ссылки. Редактору всё равно нужно проверить факты, цены, акции и alt изображений перед публикацией.

Текст редактируется прямо на холсте. Выпадающий список «Стиль текста H» превращает текущий блок в обычный текст или заголовок H1–H6; H7 сохраняется как оформленный абзац, потому что такого тега в HTML нет. Ссылка «HTML» открывает исходный код статьи для точной правки. Превью обновляется после каждого изменения. Для публикации можно передать HTML и соседнюю папку ресурсов; пути к картинкам в HTML относительные. Данные карточки товара и тексты статьи нужно проверить перед размещением.
