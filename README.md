# Редактор статей OUTMAX

В проекте также есть отдельный **Редактор email-рассылок OUTMAX / ХАСЛ**. Запустите `Редактор EMAIL OUTMAX.bat`, откройте `http://127.0.0.1:8765/email/` или перейдите в него кнопкой в верхней панели редактора статей. Он импортирует готовые HTML, ZIP и RAR и сохраняет структуру и характер исходного дизайна, включая карточки товаров, галереи, оглавление и сравнения. При экспорте несовместимые с Gmail, Яндексом, Mail.ru и Outlook конструкции преобразуются в устойчивые email-таблицы: галереи показываются в две колонки, а широкие сравнения — компактными карточками с подписями показателей. Оглавление выводится аккуратными строками, товарные карточки получают безопасные внутренние отступы, а ссылки действий — отдельные кнопки. Готовый блок заранее приведён к белому списку NotiSend: он не зависит от удаляемых сервисом семантических тегов, идентификаторов и классов содержимого, а ключевой дизайн записан inline. Редактор, готовый HTML и предпросмотр вынесены в отдельные режимы; в предпросмотре рядом показаны десктоп с максимальной шириной 700 px и телефон. Изображения загружаются по мере просмотра через локальный кеш, поэтому большие подборки не создают десятки одновременных запросов. Перед копированием или сохранением нужно выбрать OUTMAXSHOP.ru, OUTMAXSHOP.com, хасл.рф либо haslestore.com — ссылки и пути изображений становятся полными и получают выбранный домен. Для RAR на компьютере или сервере должен быть доступен UnRAR, 7-Zip либо bsdtar.

Запуск в Windows: откройте `Редактор OUTMAX.bat` (или `editor.bat`). Пункты меню: **1** — запустить редактор, **2** — сделать коммит и пуш в [GitHub](https://github.com/divangames/blogEditor), **3** — обновить [GitHub Pages](https://divangames.github.io/blogEditor/) из уже отправленного кода, **4** — отправить код в GitHub, обновить рабочий VPS и GitHub Pages, **5–8** — собрать пакеты для разных вариантов размещения, **9** — сразу обновить рабочий редактор на VPS. Пункт 9 использует ограниченный SSH-ключ из локальной папки `.deploy`, не хранит пароль VPS и сохраняет серверную папку `articles`. Меню автоматически разрешает Git работать с текущей папкой, даже если Windows показывает другого владельца каталога. Если вход GitHub устарел, пункты 2–4 откроют браузер для повторной авторизации и продолжат работу после подтверждения. Батник использует английские надписи для совместимости с `cmd.exe`. Если редактор уже работает, пункт 1 откроет его вкладку. Папка `articles/` с черновиками не публикуется в GitHub и не перезаписывается при обновлении VPS. Или в PowerShell выполните `python -m pip install -r requirements.txt`, затем `python app.py`. После запуска откройте `http://127.0.0.1:8765`.

Для полноценного размещения без отдельной главной страницы в BAT доступны пункты **6** — пакет VPS/Docker, **7** — пакет Python WSGI/Passenger и **8** — сразу оба пакета. Результаты создаются в `release/outmax-editor-docker(.zip)` и `release/outmax-editor-python-hosting(.zip)`. Оба варианта открывают редактор непосредственно по адресу `/`, поддерживают серверные черновики, изображения, импорт товаров и статей, а также защищены сгенерированным логином и паролем. Учётные данные выводятся после сборки и записываются в инструкции внутри пакета.

Кнопка «Открыть редактор онлайн» на GitHub Pages ведёт на полный редактор по адресу `https://213.139.209.107/`. VPS автоматически получает товары и статьи OUTMAX, хранит общие черновики и изображения и формирует экспортные HTML/ZIP. Статическая браузерная сборка в `docs/editor/` остаётся резервным вариантом, но основной рабочий адрес — VPS.

На широком экране левое меню и полотно статьи прокручиваются независимо. Заголовок редактора, вкладки и инструменты форматирования остаются видимыми. Превью и HTML-код прокручиваются внутри своих областей.

В поле «Товары» можно вставить несколько артикулов или ссылок через запятую или с новой строки. Поддерживаются карточки `outmaxshop.ru` и `outmaxshop.com`; для артикула без полной ссылки домен выбирается над полем ввода. Одинаковые товарные пути на `.ru` и `.com` распознаются как один товар. Карточки загружаются в боковую панель с миниатюрой и названием. Их можно перетащить на холст или вставить кнопкой. Таблица сравнения создаёт строку с миниатюрой для каждого загруженного товара и заполняет до трёх критериев подтверждёнными свойствами карточек. «Не указано» означает отсутствие сведений, а не отсутствие свойства; критерии и значения можно править вручную. При выборе ячейки таблицы доступны добавление и удаление строк и столбцов. Свои изображения можно загрузить кнопкой. «Сохранить» создаёт `articles/<название>.html`, `articles/<название>.json` и папку `articles/<название>_files` для загруженных изображений. Список товаров сохраняется в JSON и восстанавливается при открытии ZIP.

Чтобы выбрать фото товара в таблице, нажмите на миниатюру или на строку модели и затем «Выбрать фото товара». Редактор показывает кадры из галереи соответствующего товара; можно также вставить прямую HTTPS-ссылку на изображение. Выбор меняет только эту строку таблицы и сохраняется в HTML без загрузки фото на компьютер.

В панели «Содержание и разделы» можно добавлять, переименовывать, переставлять и удалять разделы, задавать им якоря. Для каждого пункта содержания можно изменить текст и выбрать цель среди разделов и товаров, вставленных в статью.

В панели «Блоки и медиа» доступна кнопка с произвольным текстом в трёх вариантах: красная, чёрная и белая с чёрной рамкой. Кнопка может вести на внешнюю ссылку или на якорь текущей статьи. Внешняя ссылка по умолчанию открывается в новом окне; для якоря эта настройка отключается автоматически.

Обычно фото с `outmaxshop.ru` и `outmaxshop.com` используются по прямым URL. Изображения с других сайтов при сохранении автоматически скачиваются в папку ресурсов и включаются в экспортный ZIP; недоступные или неподдерживаемые файлы остаются по исходному адресу с предупреждением. Галочка экспорта «Создать локальную папку с изображениями» скачивает в `image/<название статьи>` только редакционные изображения статьи и меняет их HTML-пути на адреса от корня сайта. Фотографии карточек товаров и миниатюры сравнительных таблиц остаются прямыми ссылками OUTMAX и не увеличивают архив. Щелчок по элементу статьи открывает панель удаления; у заголовка раздела можно скрыть или вернуть линию. Двойной щелчок по изображению открывает настройки кадрирования, размера, выравнивания, alt и замены файла.

Чтобы продолжить писать вне изображения, товара, таблицы или другого блока, щёлкните в свободной области холста либо выберите блок и нажмите «Текст выше» или «Текст ниже». Редактор создаст отдельный абзац и поставит в него курсор.

Для вставки раздела, товара, таблицы или изображения наведите курсор на нужный промежуток в статье и нажмите «Вставить сюда» на красной линии. Затем используйте кнопку добавления слева: новый блок появится в выбранном месте. Кнопки раздела, содержания, выделенного блока и таблицы, а также товар из панели можно перетащить прямо на нужную позицию. Чтобы переставить уже вставленный блок, выберите его и перетащите за кнопку «Перетащить блок» на новое место.

«Открыть статью (HTML/ZIP)» загружает локальный `.html`, `.htm`, JSON черновика или ZIP с HTML и папкой изображений. Для распакованного публикационного комплекта используйте «Открыть папку статьи с фото»: редактор сам выбирает HTML, находит относительные пути вроде `assets/images/...`, загружает использованные изображения и включает их в будущий ZIP. Обычный публикационный HTML автоматически адаптируется: редактор распознаёт разделы, содержание, товарные карточки, галереи и кнопки. «Адаптировать статью» можно использовать повторно для ручной перестройки уже открытого материала.

«Адаптировать статью по ссылке» принимает адреса `outmaxshop.ru/article/…`, `outmaxshop.com/article/…` и новостные адреса вида `/17-news/…` или `/news/…`; `https://` можно не вводить. Редактор загружает только содержимое статьи без меню сайта, переносит текст, разделы, содержание, карточки товаров, таблицы, фото и поддерживаемые видеоплееры, затем применяет оформление OUTMAX. Отдельные ссылки-призывы вроде «Смотреть все кроссовки →» автоматически оформляются как кнопки. При сохранении сторонние изображения скачиваются в ресурсы статьи, а изображения OUTMAX остаются по прямым URL до включения локальной папки изображений при экспорте. Импортированная статья остаётся черновиком до нажатия «Сохранить».

Кнопка «Экспорт HTML / ZIP» предлагает подготовить ссылки для `outmaxshop.ru`, `outmaxshop.com` или сразу для обоих сайтов. В последнем случае ZIP содержит два HTML-файла с одинаковым материалом и разными доменами ссылок OUTMAX. Галочка «Создать локальную папку с изображениями» формирует в ZIP готовую для загрузки в корень сайта папку `image/<название статьи>` и заменяет редакционные изображения в HTML на пути `/image/<название статьи>/...`; товарные фотографии не копируются. Итоговый HTML рассчитан на ограниченный редактор админки: всё оформление записывается в атрибуты `style`, внешний CSS и классы не требуются, а неподдерживаемые `loading`, `decoding`, `role`, `aria-*`, `data-*` и `tabindex` удаляются. Изображения OUTMAX используют обычный прямой `src`. Внутренние якоря и ссылки на сторонние сайты не изменяются.

Адаптация меняет структуру и оформление, сохраняя исходный текст и ссылки. Редактору всё равно нужно проверить факты, цены, акции и alt изображений перед публикацией.

Текст редактируется прямо на холсте. Выпадающий список «Стиль текста H» превращает текущий блок в обычный текст или заголовок H1–H6; H7 сохраняется как оформленный абзац, потому что такого тега в HTML нет. Ссылка «HTML» открывает исходный код статьи для точной правки. Превью обновляется после каждого изменения. Для публикации можно передать HTML и соседнюю папку ресурсов; пути к картинкам в HTML относительные. Данные карточки товара и тексты статьи нужно проверить перед размещением.
